## About Me

I am a pre-final year Computer Science undergraduate at VIT Vellore, focused on building AI-powered software systems that solve real-world problems at scale.

Most recently, I interned at **LTIMindtree (Noida)** as a Software Engineering Intern, where I architected a billing microservice using Java 17, Spring Boot, and MySQL — implementing circuit breaker patterns for fault-tolerant inter-service communication and applying object-oriented design principles across a multi-module architecture. During the same internship, I built **AgentReg**, an autonomous 4-stage agentic pipeline that reduced regulatory compliance review time from 3–6 weeks to under 10 minutes, powered by a custom RAG pipeline with FastAPI async streaming and multi-model fallback chains.

On the project side, I designed **CodeCarbonOps**, a carbon-aware AI inference routing system that dynamically distributes LLM workloads across 15 global regions using Thompson Sampling and real-time grid-carbon telemetry — achieving up to 93% reduction in per-request CO2 emissions. I also built **EduEase**, an adaptive learning platform for neurodivergent students featuring attention-aware TTS, webcam-based distraction detection, and a production RAG pipeline with parent-child chunking and per-session memory.

I am actively seeking **placements and 6-month internships (PPO track)** starting 2027.
